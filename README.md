# KiranaIQ (demo)

SKU-level demand forecasts, voice-based inventory entry, and stockout alerts for
small grocery (kirana) stores. This repo is the **demo build**: everything runs
locally, no paid APIs, no cloud, no billing.

> ⚠️ **All sales data is SYNTHETIC.** It is generated by `backend/seed.py`
> (random base demand + weekend seasonality + noise + festival spikes). It is
> **not** real data from any store. The forecast accuracy numbers (WAPE) are
> real backtest results computed on this synthetic data.

---

## What's inside

```
kiranaiq/
  backend/   FastAPI + SQLite + LightGBM + faster-whisper + APScheduler
  mobile/    Expo (React Native, TypeScript) app — runs in Expo Go
  README.md  (this file)
```

Tech choices for the demo:
- **Backend:** FastAPI, SQLAlchemy over SQLite (DB access isolated in `db.py` so
  Postgres is a one-line swap later).
- **ML:** one global **LightGBM** model + a **7-day moving-average baseline**,
  compared by **WAPE** on a 28-day backtest.
- **Voice:** **faster-whisper** (`base`, CPU, int8) + a rule-based parser
  (`rapidfuzz` fuzzy-matches spoken items to your SKUs).
- **Scheduler:** APScheduler nightly job + a manual "Run check now" endpoint.
- **Mobile:** Expo Go only (no custom dev build). Charts use `react-native-svg`.
  Audio uses `expo-audio` (the current replacement for the removed `expo-av`).

## 1. Run the backend

Requires Python 3.11+.

### First time (installs dependencies)
```powershell
cd kiranaiq/backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```
(macOS/Linux: `python -m venv .venv && .venv/bin/python -m pip install -r requirements.txt`)

### Every time (seed + serve)
**Windows:**
```powershell
cd kiranaiq/backend
.\run.ps1
```
**macOS / Linux / Git Bash:**
```bash
cd kiranaiq/backend
./run.sh
```
Or the raw one-liner (bash / PowerShell 7+):
```bash
python seed.py && uvicorn main:app --host 0.0.0.0 --port 8000
```

On startup the server **seeds data, trains the forecast model, and preloads the
Whisper model**, so the first forecast and the first voice request are fast.
The very first launch downloads the Whisper `base` model (~140 MB) once.

Check it's up: open http://localhost:8000/health → `{"status":"ok"}`.
API docs (handy during the review): http://localhost:8000/docs

## 2. Find your laptop's LAN IP

Your phone must reach the laptop over WiFi, so the app needs the laptop's LAN IP
(not `localhost`).

- **Windows:** run `ipconfig` → look for **IPv4 Address** (e.g. `192.168.1.42`).
  Shortcut: `(Get-NetIPAddress -AddressFamily IPv4 | Where-Object {$_.IPAddress -like '192.168.*' -or $_.IPAddress -like '10.*'}).IPAddress`
- **macOS:** `ipconfig getifaddr en0`
- **Linux:** `hostname -I`

Phone and laptop must be on the **same WiFi**. If the phone can't connect, allow
Python through the Windows Firewall (Private networks) for port 8000.

## 3. Run the mobile app (Expo Go)

1. Install **Expo Go** on your phone (App Store / Play Store).
2. Put your laptop IP into the **one config file**:
   `mobile/src/config.ts` →
   ```ts
   export const API_BASE_URL = 'http://192.168.1.42:8000'; // <-- your laptop IP
   ```
3. Start Expo:
   ```bash
   cd kiranaiq/mobile
   npm install        # first time only
   npx expo start
   ```
4. Scan the QR code with your phone (Expo Go). The app opens with three tabs:
   **Inventory**, **Add by Voice**, **Alerts**.

## 4. Two-minute demo script

1. **Inventory tab** — show the SKU list. Rice / Sugar / Milk show a red **LOW**
   badge.
2. **Tap Rice** — the forecast detail screen shows a 7-day bar chart
   (**LightGBM** green vs **baseline** grey) and the **WAPE comparison**
   (LightGBM ~14% vs baseline ~20% — lower is better, so the model wins).
3. **Add by Voice tab** — tap **🎤 Start recording**, say
   *"ten kilo rice, five packet biscuits, two litre oil"*, tap **Stop &
   transcribe**. Show the transcript + parsed rows.
   - *(If the mic acts up: use the **type instead** box with the same sentence —
     it runs through the exact same parser.)*
4. **Review & confirm** — the rows are editable; tap **Confirm & save**. Flip to
   the Inventory tab to show Rice's stock went up.
5. **Alerts tab** — tap **🔄 Run check now**. Stockout alerts appear, e.g.
   *"Rice: stock 8 kg, expected demand 71 kg in 3 days. Reorder now."*
6. Tap **👍 Useful** on an alert to record feedback.

## API reference (quick)

| Method | Path | Purpose |
|---|---|---|
| GET  | `/health` | liveness |
| GET  | `/items` | list SKUs (with `low_stock` flag) |
| POST | `/items` | create a SKU |
| PUT  | `/items/{id}/stock` | set stock level |
| POST | `/items/bulk` | confirm reviewed voice rows (restock or create) |
| GET  | `/forecast/{id}` | 7-day forecast (LightGBM + baseline + metrics) |
| GET  | `/metrics` | backtest WAPE for both models |
| POST | `/voice/transcribe` | audio upload → transcript + parsed rows |
| POST | `/voice/parse-text` | typed text → parsed rows (fallback) |
| GET  | `/alerts` | list alerts |
| POST | `/alerts/run` | run the stockout check now |
| POST | `/alerts/{id}/feedback` | mark an alert useful / not useful |
